# FoodieGO – Food Delivery Mobile App UI/UX Design

## Task 1 – Food Delivery Mobile App Design

### Project Description
FoodieGO is a food delivery mobile application UI/UX design created using Google Stitch. The project focuses on providing a simple, modern, and user-friendly food ordering experience.

### Objective
To design an attractive and easy-to-use food delivery mobile application that helps users explore restaurants, select food, and place orders.

### Tools Used
- Google Stitch
- UI/UX Design
- GitHub

### Screens Designed
1. Home Screen
2. Food Details Screen
3. Restaurant Listing Screen
4. Cart Screen
5. Checkout Screen
6. Order Tracking Screen

### Key Features
- Food categories
- Restaurant browsing
- Search and filters
- Food details
- Add to cart
- Checkout interface
- Order tracking
